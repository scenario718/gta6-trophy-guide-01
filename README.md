Leonida Night Ledger is an offline tracker and platinum roadmap for the 55 PlayStation 5 trophies in Grand Theft Auto VI. It keeps the official name, description, and grade for every trophy, saves your checks in the browser, and filters the list by story, missables, collectibles, and activities, plus grade and search. A spoiler switch covers unearned story trophies. Each trophy opens into a short original guide, a missable note derived from its official description, and a plain-text citation.

Run it with `node serve.ts`, then open http://localhost:8080. No install and no build step. Progress exports and imports as JSON.
